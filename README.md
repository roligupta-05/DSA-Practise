# DSA Practice Using Java

This repository contains my practice programs for Data Structures and Algorithms using Java. I am using it to improve my programming fundamentals, develop problem-solving skills, and understand how different data structures and algorithms work.

## Topics

* Java programming basics
* Arrays and strings
* Searching and sorting
* Linked lists
* Stacks and queues
* Recursion
* Trees and graphs
* Dynamic programming

Topics and solutions will be added as I progress through the syllabus.

## Tools Used

* Java
* Visual Studio Code
* Git
* GitHub

## Repository Structure

Programs are organized into folders according to their topics. Each Java file contains an individual program or problem solution.

```text
dsa-java-practice/
├── README.md
├── .gitignore
├── 00-basics/
├── 01-arrays/
├── 02-strings/
└── 03-searching-sorting/
```

Additional folders will be created as new topics are covered.

## Practice Approach

For each problem, I try to understand the logic, implement the solution, test it with different inputs, and analyse its time and space complexity where applicable.

I also use Git to track changes and maintain my solutions in one place for future revision.

## Purpose

The purpose of this repository is to maintain a record of my DSA practice, revise important concepts, and improve my coding skills through regular practice.
